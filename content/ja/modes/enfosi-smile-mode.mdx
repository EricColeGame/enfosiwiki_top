## 上級戦術と避けるべき典型的な失敗

経験豊富なチームであっても、終盤の想定外の事態には苦戦を強いられることがあります。本モードを深層まで生き残るには、統率の取れた連携、正確なターゲット選択、そしてアリーナのハザードに対する鋭い危機管理が求められます。

最も頻繁に見られるミスの1つは、HPの減った敵を深追いして防衛ラインを越えてしまう「オーバーエクステンド（深追い）」です。Smile Modeでは敵の出現間隔が短いため、無謀に前進したプレイヤーは数秒で新たなウェーブに側面を突かれ、退路を断たれて主力ディーラーが孤立してしまいます。

チームの連携と戦術精度を高めるために、以下のよくある失敗と改善策を確認してください。

| よくある失敗 | 戦略的結果 | 改善策 |
| :--- | :--- | :--- |
| **強欲なゴールド温存** | 中盤ステータスの不足によりウェーブ6でレーンが決壊する | コスパに優れた中継ぎアイテムを購入し、ステータス曲線を先行する |
| **CC（行動不能）の重複発動** | スタン持続時間が無駄になり、ボスが脱出して後衛を殲滅する | 明確なCCローテーション順序を策定する（例：タンクのスタン → サポートの追撃） |
| **タレット（防衛線）を越えた深追い** | 背後から新規出現した敵に挟み撃ちにされる | 狭路のラインを維持し、準備されたキルゾーンへ敵をおびき寄せる |
| **オーラの重複無視** | パッシブ効果の無駄な重複によりチーム全体の総合力が低下する | ユニークなチームオーラが重複しないよう、事前に購入担当を連携する |
| **激昂（エンレージ）時のパニック** | 陣形が乱れ、ボスに単独ターゲットを各個撃破される | 直ちに再集結し、外周に沿ってカイトしながら火力を集中させる |

さらに、プレイヤーの経験から、補助的な出現通路の視界（ビジョン）を確保しておくことで奇襲を防げることが分かっています。偵察用ワードを配置したり、スポーンポータル付近の視界を維持したりすることで、危険なウェーブが防衛拠点（コア）に接触する前に再配置するための貴重な数秒間を稼ぐことができます。

## Enfosi Smile Modeに関するよくある質問（FAQ）

### Enfosi Smile Modeは通常難易度と何が違いますか？
主な違いは、短縮されたウェーブ出現間隔、クールダウンの加速、そして動的なモディファイア（アフィックス）にあります。このモードでは敵のウェーブが非常に速いテンポで出現するため、戦闘間のインターバルがほとんどありません。また、敵集団には移動速度の上昇、呪文耐性、地面設置ハザードなどの特殊効果が付与されており、絶え間ない戦術の調整が求められます。

### Enfosi Smile Modeではゴールドをどのように優先配分すべきですか？
高価なティア4のレジェンダリーアイテムを目指してゴールドを貯め込むのではなく、クールダウン短縮、サステイン（維持力）、ウェーブクリア能力を提供するコストパフォーマンスの高い中級アイテムを優先すべきです。即座にステータスを引き上げることで、ゲームのテンポから遅れることなく、中盤ウェーブの急激な敵の強化に対処できます。

### このモードで初心者にとって最適なヒーロー構成はどれですか？
高耐久のフロントラインタンク1名、補完的なダメージディーラー2名（広範囲処理用の魔法系1名と対ボス火力用の物理系1名）、そしてCCに特化したサポート1名からなるバランスの良い構成が最も安定します。この構成であれば、多彩なウェーブギミックに対処するのに十分なピール力、バースト火力、継戦能力を確保できます。

### Enfosi Smile Modeはソロ（1人）でクリアできますか？
ほぼ完璧なカイト技術と最適なヒーロー選択ができる最上位プレイヤーであれば技術的には可能ですが、ソロでのクリアは極めて困難です。急速な出現ペースや重複するCCデバフは協力プレイを前提に調整されているため、連携の取れたチームの方が最終ボスステージをクリアできる確率は圧倒的に高くなります。
